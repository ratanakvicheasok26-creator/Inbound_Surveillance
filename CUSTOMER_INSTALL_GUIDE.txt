--------------------------------------------------------------------
STEP 1: DOWNLOAD & EXTRACT
--------------------------------------------------------------------
1. Download "Champei_Spa_Intelligence.zip" from the link above.
2. Right-click the ZIP file and select "Extract All...".
3. Choose a folder destination (e.g., C:\Champei_Spa_Intelligence) and click "Extract".

--------------------------------------------------------------------
STEP 2: INSTALL PYTHON (If not already installed)
--------------------------------------------------------------------
1. Download Python (version 3.10, 3.11, or 3.12) from:
   https://www.python.org/downloads/
2. Run the installer.
3. [CRITICAL]: Make sure to check the box:
   [✔] "Add Python to PATH" (at the bottom of the installer window).
4. Click "Install Now" and finish setup.

--------------------------------------------------------------------
STEP 3: 1-CLICK AUTOMATIC SETUP
--------------------------------------------------------------------
1. Open your extracted "Champei_Spa_Intelligence" folder.
2. Double-click "INSTALL_WINDOWS.bat".
3. Wait 1-2 minutes while it configures components and runs diagnostics.
4. When finished, press any key to close the window.

--------------------------------------------------------------------
STEP 4: RUNNING THE APPLICATION
--------------------------------------------------------------------
- Double-click the new "Champei Spa Intelligence" shortcut on your Desktop.
  (Or double-click "start_champei.bat" inside the folder).
- The system will open your camera surveillance and analytics dashboard.
